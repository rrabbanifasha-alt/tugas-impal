# 1. PENDAHULUAN

## 1.4 Referensi

Dokumen Spesifikasi Kebutuhan Perangkat Lunak (SKPL) ini disusun berdasarkan beberapa referensi standar rekayasa perangkat lunak, studi pustaka domain *e-grocery*, standar pengujian kebergunaan, serta dokumentasi integrasi teknologi yang benar-benar diterapkan dalam perancangan sistem:

1. **IEEE Computer Society. (1998)**.  
   *IEEE Std 830-1998: IEEE Recommended Practice for Software Requirements Specifications*. IEEE Standards Coordinating Committee.  
   *(Digunakan sebagai pedoman standar internasional dalam menyusun struktur bab, tata cara perumusan kebutuhan fungsional, kebutuhan non-fungsional, serta batasan operasional perangkat lunak)*.

2. **Program Studi S1 Informatika Universitas Telkom. (2026)**.  
   *Spesifikasi Kebutuhan Perangkat Lunak (SKPL) KITANI: Aplikasi Pemasaran Hasil Pertanian Berbasis Android*. Fakultas Informatika, Universitas Telkom.  
   *(Digunakan sebagai acuan format template resmi, struktur penomoran bab, layout header-footer kerahasiaan, serta format baku tabel skenario use case kampus)*.

3. **Brooke, J. (1996)**.  
   *SUS: A 'quick and dirty' usability scale*. Usability Evaluation in Industry, Taylor & Francis, London, 189–194.  
   *(Digunakan sebagai metodologi pengukuran kuantitatif pada spesifikasi kebutuhan non-fungsional kemudahan antarmuka NFR-USB-01 melalui kuesioner System Usability Scale)*.

4. **Kecipir Indonesia. (2023)**.  
   *Kecipir: Platform Belanja Sayur Organik Online Bebas Sampah Plastik (Zero-Waste E-Grocery)*. https://kecipir.com/  
   *(Digunakan sebagai rujukan studi kasus model operasional distribusi sayur ramah lingkungan dengan kemasan besek bambu dan alas daun pisang alami)*.

5. **WhatsApp LLC & Meta Platforms Inc. (2024)**.  
   *WhatsApp Direct Chat & URI Scheme Specification: wa.me Linking*. Meta Developer Documentation. https://faq.whatsapp.com/  
   *(Digunakan sebagai acuan teknis dalam perancangan mekanisme pemesanan terbimbing WhatsApp-assisted checkout tanpa pihak ketiga melalui protokol tautan `https://wa.me`)*.
