# LAMPIRAN A: DAFTAR KATA-KATA ASING (GLOSARIUM)

Dokumen ini memuat glosarium istilah asing, peristilahan teknis rekayasa perangkat lunak, terminologi bisnis pangan organik, singkatan, serta istilah spesifik proyek yang digunakan di dalam dokumen **Spesifikasi Kebutuhan Perangkat Lunak (SKPL) Sayur Ikat**. Glosarium ini diklasifikasikan ke dalam 5 (lima) tabel tematik sesuai dengan standar penyusunan SKPL Program Studi S1 Informatika Universitas Telkom.

---

### Tabel A: Istilah Umum Sistem

| No. | Istilah Asing | Definisi / Penjelasan |
| :-: | :--- | :--- |
| 1. | *Client-Server* | Arsitektur komputasi terdistribusi yang membagi beban kerja antara penyedia sumber daya/layanan (*server*) dan peminta layanan (*client*). |
| 2. | *Web Browser* | Perangkat lunak aplikasi yang digunakan pengguna untuk mengakses, mengambil, dan menyajikan sumber daya informasi di *World Wide Web*. |
| 3. | *Responsive Web Design* | Pendekatan desain web yang membuat antarmuka halaman dapat menyesuaikan tata letak (*layout*) secara proporsional sesuai ukuran layar (*viewport*) perangkat. |
| 4. | *Viewport* | Area tampilan visual yang terlihat oleh pengguna pada layar peramban komputer atau ponsel pintar. |
| 5. | *Mobile-First* | Strategi perancangan antarmuka perangkat lunak yang memprioritaskan tata letak dan kinerja pada perangkat layar sentuh seluler sebelum diadaptasi ke layar desktop. |
| 6. | *Persistent Disk* | Media penyimpanan data fisik maupun virtual yang mempertahankan integritas data secara permanen meskipun sistem operasi atau peladen dimatikan/dimuat ulang. |
| 7. | *Reverse Proxy* | Peladen perantara yang menerima permintaan klien di pintu depan jaringan dan meneruskannya ke peladen web aplikasi di belakangnya, sering digunakan untuk terminasi enkripsi TLS/HTTPS dan *caching*. |

### Tabel B: Istilah Teknis Perangkat Lunak

| No. | Istilah Asing | Definisi / Penjelasan |
| :-: | :--- | :--- |
| 1. | *App Router* | Paradigma perutean berbasis struktur folder berkas (*file-system routing*) pada Next.js yang mendukung tata letak bersarang (*nested layouts*) dan *React Server Components*. |
| 2. | *Route Handlers* | Fungsi pengendali pada Next.js App Router yang memungkinkan pembuatan titik akhir antarmuka program (*REST API endpoints*) untuk melayani metode HTTP. |
| 3. | *Server-Side Rendering (SSR)* | Mekanisme pembuatan dokumen HTML secara dinamis pada peladen sebelum dikirimkan ke peramban klien guna mempercepat waktu muat awal dan optimasi SEO. |
| 4. | *Object-Relational Mapping (ORM)* | Teknik pemrograman untuk mengonversi dan memetakan data antara sistem basis data relasional dengan model objek pada bahasa pemrograman berorientasi objek. |
| 5. | *Type-Safe* | Karakteristik bahasa atau pustaka pemrograman yang menjamin bahwa tipe data diverifikasi secara ketat saat kompilasi guna mencegah kesalahan logika saat eksekusi (*runtime error*). |
| 6. | *Parameterized Query* | Teknik eksekusi kueri basis data di mana nilai masukan dipisahkan dari sintaks instruksi SQL, secara efektif mencegah celah keamanan injeksi perintah SQL (*SQL Injection*). |
| 7. | *LocalStorage* | Fitur penyimpanan data lokal sisi klien standar HTML5 Web Storage yang menyimpan data berbentuk pasangan kunci-nilai tanpa batasan kedaluwarsa waktu sesi. |
| 8. | *Base64 Data URL* | Skema pengkodean data biner (seperti gambar) ke dalam representasi teks berkarakter ASCII standar yang dapat disematkan secara langsung di dalam format JSON atau HTML. |
| 9. | *Payload* | Muatan data aktual atau badan pesan (*body message*) yang ditransmisikan dalam permintaan (*request*) atau tanggapan (*response*) protokol jaringan HTTP. |
| 10. | *Cache-Control* | *Header* HTTP yang mendefinisikan instruksi penyimpanan sementara (*caching*) bagi peramban dan peladen perantara untuk mencegah pemuatan data inventaris yang kedaluwarsa. |

### Tabel C: Istilah pada Domain Bisnis

| No. | Istilah Asing / Bisnis | Definisi / Penjelasan |
| :-: | :--- | :--- |
| 1. | *Zero-Waste* | Filosofi dan praktik operasional ramah lingkungan yang menargetkan peniadaan sampah sekali pakai menuju tempat pemrosesan akhir (TPA). |
| 2. | *Plastic-Free Packaging* | Pengemasan produk yang sepenuhnya mengeliminasi penggunaan kantong atau pembungkus plastik sekali pakai, digantikan oleh daun pisang alami dan tali rami/bambu. |
| 3. | *Besek Bambu* | Kotak wadah tradisional ramah lingkungan berbahan anyaman bambu alami yang dapat digunakan kembali (*reusable*) atau terurai secara hayati (*biodegradable*). |
| 4. | *Farm-to-Table* | Rantai pasok pangan pendek yang menghubungkan hasil panen segar langsung dari petani lokal di daerah pegunungan (Lembang, Ciwidey, Pangalengan) ke dapur konsumen. |
| 5. | *Cut-Off Time* | Batas waktu akhir pemesanan harian (pukul 12.00 WIB) yang menjadi patokan apakah pesanan dikirim pada hari yang sama (*same-day*) atau jadwal panen esok pagi (*next-day*). |
| 6. | *Same-Day Delivery* | Layanan logistik pengantaran komoditas sayur segar ke alamat pelanggan pada hari yang sama saat pesanan diverifikasi. |
| 7. | *Bundle Package* | Paket komoditas sayuran siap masak yang dikelompokkan berdasarkan menu hidangan harian keluarga (seperti Paket Sayur Asam atau Paket Sop). |
| 8. | *Quality Assurance (QA)* | Prosedur penjaminan dan pemeriksaan kesegaran sayuran sebelum dikemas untuk memastikan kepuasan konsumen bebas dari daun busuk atau hama. |
| 9. | *Garansi Kompensasi* | Kebijakan perlindungan mutu Sayur Ikat di mana sayuran yang terbukti layu atau rusak diganti dengan produk baru atau pengembalian saldo tanpa prosedur rumit. |

### Tabel D: Singkatan dan Akronim

| No. | Singkatan / Akronim | Kepanjangan Resmi | Definisi / Keterangan |
| :-: | :--- | :--- | :--- |
| 1. | **SKPL** | Spesifikasi Kebutuhan Perangkat Lunak | Dokumen formal rekayasa perangkat lunak yang memuat seluruh kapabilitas dan batasan sistem (adaptasi IEEE Std 830-1998). |
| 2. | **DPPL** | Deskripsi Perancangan Perangkat Lunak | Dokumen perancangan teknis arsitektur perangkat lunak (adaptasi IEEE Std 1016-2009). |
| 3. | **FR** | *Functional Requirement* | Persyaratan yang mendefinisikan fungsi atau kapabilitas yang harus disediakan perangkat lunak. |
| 4. | **NFR** | *Non-Functional Requirement* | Persyaratan yang menetapkan kriteria kualitas, performa, keamanan, dan keandalan sistem. |
| 5. | **UI** | *User Interface* | Tampilan visual grafis antarmuka yang menghubungkan interaksi antara manusia dan komputer. |
| 6. | **UX** | *User Experience* | Persepsi dan respons emosional pengguna yang timbul dari kemudahan penggunaan aplikasi. |
| 7. | **API** | *Application Programming Interface* | Sekumpulan protokol dan definisi fungsi yang memungkinkan komunikasi antarkomponen perangkat lunak. |
| 8. | **REST** | *Representational State Transfer* | Gaya arsitektur komunikasi layanan web tanpa status (*stateless*) berbasis protokol HTTP. |
| 9. | **JSON** | *JavaScript Object Notation* | Format pertukaran data berbasis teks ringan yang mudah dibaca oleh manusia maupun mesin komputasi. |
| 10. | **ORM** | *Object-Relational Mapping* | Lapisan abstraksi perangkat lunak yang memetakan baris tabel database ke dalam objek kode program. |
| 11. | **DBMS** | *Database Management System* | Perangkat lunak pengelola penyimpanan, pembaruan, dan pengambilan data terstruktur. |
| 12. | **ACID** | *Atomicity, Consistency, Isolation, Durability* | Standar sifat keandalan transaksi basis data yang menjamin transaksi diproses secara utuh atau dibatalkan sama sekali. |
| 13. | **HTTP** | *Hypertext Transfer Protocol* | Protokol lapisan aplikasi untuk transmisi dokumen hipermedia di jaringan internet. |
| 14. | **HTTPS** | *Hypertext Transfer Protocol Secure* | Protokol HTTP yang diamankan dengan enkripsi lapisan transportasi (TLS). |
| 15. | **TLS** | *Transport Layer Security* | Protokol kriptografi standar industri yang menyediakan privasi dan integritas komunikasi data internet. |
| 16. | **URI / URL** | *Uniform Resource Identifier / Locator* | Format penamaan alamat global standar untuk mengidentifikasi berkas atau layanan web. |
| 17. | **CDN** | *Content Delivery Network* | Jaringan peladen terdistribusi secara geografis untuk mempercepat pengiriman aset media statis (gambar). |
| 18. | **COD** | *Cash on Delivery* | Mekanisme pembayaran tunai langsung kepada pihak pengantar barang saat pesanan sampai. |
| 19. | **QRIS** | *Quick Response Code Indonesian Standard* | Standar nasional sistem pembayaran kode QR digital yang ditetapkan oleh Bank Indonesia. |
| 20. | **SUS** | *System Usability Scale* | Skala kuesioner terstandar internasional (10 instrumen pertanyaan) untuk mengukur tingkat kegunaan antarmuka aplikasi. |
| 21. | **LCP** | *Largest Contentful Paint* | Metrik performa antarmuka yang mengukur durasi waktu render blok konten visual terbesar pada layar pengguna. |

### Tabel E: Istilah Khusus Proyek Sayur Ikat

| No. | Istilah Khusus | Penjelasan Kontekstual dalam Proyek |
| :-: | :--- | :--- |
| 1. | *Guest Checkout* | Alur pemesanan langsung tanpa pembeli harus melalui tahapan registrasi akun atau memasukkan kata sandi, cukup mengisi nama, WhatsApp, dan alamat. |
| 2. | *Slide-Over Cart Drawer* | Komponen panel geser dari tepi kanan layar peramban yang menampung daftar produk keranjang belanja, kalkulasi ongkos kirim otomatis, serta formulir checkout. |
| 3. | *Grill Us Feedback* | Modul formulir evaluasi mutu purna jual (`/feedback`) yang memungkinkan konsumen memberi ulasan transparan serta melampirkan foto bukti fisik untuk garansi produk. |
| 4. | *WhatsApp Click-to-Chat* | Mekanisme pengiriman pesanan dan penerusan ulasan yang memanfaatkan protokol `https://wa.me/` untuk menyusun teks draf pesanan otomatis tanpa instalasi pustaka pihak ketiga berbayar. |
| 5. | *Quick Stock Toggle* | Tombol aksi cepat satu kali klik pada dasbor pengelolaan produk untuk mengubah status stok komoditas dari 30 (aktif) menjadi 0 (nonaktif), atau sebaliknya. |
| 6. | *Bandung Raya Delivery Area* | Batasan wilayah operasional pengiriman eksklusif sistem yang mencakup Kota Bandung, Kota Cimahi, Kabupaten Bandung, dan Kabupaten Bandung Barat. |
